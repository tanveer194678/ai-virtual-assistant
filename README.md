# 🤖 AI Virtual Assistant

A Python-based AI Virtual Assistant capable of understanding voice commands and performing tasks like opening websites, searching Wikipedia, telling the current time, and responding using text-to-speech.

## ✨ Features

- 🎤 Voice Recognition
- 🔊 Text-to-Speech
- 🌐 Open Websites
- 📚 Wikipedia Search
- ⏰ Current Time
- 💬 Voice Commands

## 🛠 Technologies Used

- Python
- SpeechRecognition
- pyttsx3
- pywhatkit
- Wikipedia
- webbrowser

## 📂 Project Structure

```
ai-virtual-assistant/
│
├── main.py
├── README.md
└── requirements.txt
```

## 🚀 Installation

```bash
pip install -r requirements.txt
```

## ▶️ Run

```bash
python main.py
```
